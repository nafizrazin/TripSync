# Legacy project reference

This folder contains the application PHP files from the original DBMS project. It is kept only to show the starting point of the TripSync modernization.

The public repository intentionally omits the old sample database rows, third-party template libraries, bundled fonts, and image assets. They are not runtime dependencies of the current application and the old database dump contained plaintext sample credentials and personal-looking placeholder data.

See [`../docs/legacy-audit.md`](../docs/legacy-audit.md) for the technical comparison between the legacy design and the current system.
